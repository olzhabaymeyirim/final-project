## Project Description

Moon & Movies is a group project focused on creating an outdoor cinema website. The website allows users to explore movies, view movie schedules, and use contact and registration forms.

The project combines a consistent design, responsive layouts, and interactive features to provide a simple user experience.

## Features

- Personalized welcome message
- Dark and light theme switcher
- FAQ accordion
- Movie search and category filtering
- Movie wishlist
- Required form fields
- Email validation
- Password confirmation
- Success and error messages
- Reset button
- Responsive design for different screen sizes

## Technologies

- HTML5
- CSS3
- JavaScript
- jQuery 3.7.1
- Bootstrap 5

## How to Run

1. Open or download the project repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in a browser or use the Live Server extension.
4. Navigate through the website using the navigation menu.
5. Open `register.html` or `contact.html` to test the forms.
